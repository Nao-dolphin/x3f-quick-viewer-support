Data collection

X3F Quick Viewer does not transmit or collect personal information, photos, shooting metadata, usage data, device identifiers, or other user data to the developer or any third party.

File processing

All processing is performed on the Mac. The app never modifies the original X3F and reads only the embedded JPEG data needed for display. A limited temporary cache for Finder thumbnails is stored in the macOS app-extension container and old items are removed.

Network and third-party SDKs

The app has no network entitlement or network feature. It includes no advertising, analytics, tracking, account, or cloud-storage SDK.

Changes

This page will be updated if the app’s features or data practices change.
