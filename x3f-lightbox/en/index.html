X3F DNG Lightbox

Support

Connect both devices to the same local network and publish a photo folder in a compatible X3F DNG Select Mac app. Select the Mac using the iPad folder button. Previously received sets open directly from Saved on This iPad, including when changes are pending. To synchronize, publish the corresponding folder on the originating Mac and tap Sync on iPad. If Local Network permission was denied, enable it in iPad Settings. Loading your own photos requires the compatible Mac app.

Requires iPadOS 17 or later. Japanese and English.
