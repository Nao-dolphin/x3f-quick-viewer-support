公開方法:
1. GitHubでPublicリポジトリ x3f-quick-viewer-support を作成
2. この03_Support_Websiteフォルダ内のファイルを、リポジトリのルートへアップロード
3. Settings → Pages
4. Build and deployment: Deploy from a branch
5. Branch: main / root
6. Save
7. 数分後、上記URLへアクセスして表示確認

注意:
アプリのソースコードはこのリポジトリへ入れません。
サポートページとプライバシーポリシーだけを公開します。
