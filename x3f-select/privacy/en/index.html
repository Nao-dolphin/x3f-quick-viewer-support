Privacy Policy

X3F DNG Select — effective August 31, 2026; last updated September 5, 2026

Local processing

The app processes image files selected by the user locally on the Mac. It does not upload image files, previews, Exif information, folder names, or file names to a developer-operated server.

Accounts, advertising, and analytics

The app does not use accounts, advertising, tracking, usage analytics, or third-party data-collection SDKs.

Information stored on the Mac

A per-photo Asset ID, a fingerprint derived from RAW file content, decisions, display rotation, filters, recent-folder history and security-scoped access bookmarks, and contact-sheet settings are stored in the app's private area for recognition and restoration. Nothing is written into the RAW file.

Optional iPad companion

Only when the iPad Lightbox companion is used, the app uses Bonjour and Apple's Network.framework to send review previews and review metadata directly to the iPad selected by the user on the same local network, and to synchronize decisions and display rotations back to the Mac. No developer-operated server or cloud service is involved. The per-Mac identifier is used only to distinguish synchronization sources.

Apple processing

macOS and the App Store may process purchase, download, and diagnostic information under Apple's own policies. This is separate from the handling of image files by X3F DNG Select.

Contact

The email address, message, and attachments a user voluntarily sends to support are used to respond to the request. They are deleted when no longer needed, unless retention is required by law or for a legitimate operational reason.
