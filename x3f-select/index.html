X3F DNG Select

対応するSIGMA X3F／DNGをすばやく見比べ、必要な元RAWだけを安全に選び出します。

Version 1.0.0 · 元ファイルを編集・移動・削除しません

使い方と対応範囲を見る

一覧と比較

埋め込みプレビューを優先し、1枚・2枚・4枚表示で対応X3F／DNGを比較します。

○／△／×で選別

採用・保留・不採用・未判定をキーボードでもすばやく設定できます。

安全なSelectedコピー

採用した元RAWの複製だけをSelectedへ作成。同一内容はスキップし、同名別内容を上書きしません。

Exifと出力

Exifフィルター、表示回転、コンタクトシートPDF、印刷、セッション復元に対応します。

確認済みの範囲

代表実ファイルで、SIGMA DP1 Merrill／DP3 MerrillのX3F、およびSIGMA fp LのDNGを確認しています。すべてのX3F、DNG、カメラ、ファームウェア、撮影モードへの対応を保証するものではありません。X3FセンサーデータをDNGへ変換するアプリではありません。

プライバシー

画像とExifはMac上で処理され、開発者のサーバーへアップロードされません。アカウント、広告、トラッキング、利用分析、第三者データ収集SDKは使用しません。
