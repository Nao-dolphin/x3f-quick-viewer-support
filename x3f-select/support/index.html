X3F DNG Select サポート

Version 1.0.0 — macOS 14以降

操作、対応範囲、制約、問い合わせ方法をまとめています。

基本操作

  1. 「フォルダを開く」でX3Fまたは対応DNGを含むフォルダを選びます。選択画面ではCommand-Shift-Gでパスを入力できます。
  2. 1枚・2枚・4枚表示で比較し、1=採用、2=保留、3=不採用、0=未判定を指定します。
  3. [ と ] で表示だけを90°回転できます。
  4. 出力メニューの「○採用をSelectedへコピー」で、採用した元RAWの複製を作成します。

元RAWを編集・移動・削除せず、同名ファイルを無言で上書きしません。コピー後に成功・失敗・スキップ件数とSelectedフォルダを確認してください。

対応ファイル

代表実ファイルで確認済み：SIGMA DP1 Merrill／DP3 MerrillのX3F、SIGMA fp LのDNG。

埋め込みJPEGプレビューを優先します。すべてのX3F、DNG、カメラ、ファームウェア、撮影モードを保証するものではありません。本アプリはX3Fセンサーデータから新しいDNGを生成しません。

既知の制約

  • 破損ファイル、未確認機種、特殊なX3F/DNGは表示またはExif取得ができない場合があります。
  • プレビューの色、階調、解像感、Exifは最終現像結果と異なる場合があります。
  • 空き容量、アクセス権、外部／ネットワークドライブの切断、スリープでコピーが失敗する場合があります。
  • 直接DNG解析はBigTIFFや複数ストリップ／タイルに分割されたJPEGプレビューに対応していません。

よくある質問

プレビューが表示されません。
アプリ内の「対応ファイル」と「重要なご案内」を確認してください。未対応・破損ファイルはファイル単位のエラーとして表示されます。

コピーは元ファイルを変更しますか。
変更しません。Selectedへ複製し、同一内容はスキップ、同名別内容は連番名で保存します。

フォルダをパスで指定できますか。
フォルダ選択画面でCommand-Shift-Gを押し、パスを入力してください。
