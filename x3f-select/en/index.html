X3F DNG Select

Quickly compare supported SIGMA X3F and DNG photographs, then safely select the original RAW files you want.

Version 1.0.0 · Originals are never edited, moved, or deleted

View workflow and compatibility

Browse and compare

Prefer embedded previews and compare supported X3F/DNG files in 1-up, 2-up, or 4-up views.

○ / △ / × culling

Set Accepted, Hold, Rejected, or Unreviewed states quickly, including from the keyboard.

Safe Selected copies

Copy only accepted original RAW files to Selected. Identical files are skipped and different same-named files are never overwritten.

Exif and output

Use Exif filters, display rotation, contact-sheet PDF, printing, and session restoration.

Verified scope

Representative real files have been verified for X3F from SIGMA DP1 Merrill and DP3 Merrill cameras and DNG from a SIGMA fp L. Support for every X3F, DNG, camera, firmware, or shooting mode is not guaranteed. The app does not convert X3F sensor data into DNG.

Privacy

Images and Exif are processed on the Mac and are not uploaded to a developer-operated server. The app uses no account, advertising, tracking, usage analytics, or third-party data-collection SDK.
