# X3F Quick Viewer Support

Public support and privacy pages for **X3F Quick Viewer**, a macOS utility that displays SIGMA X3F files as Finder thumbnails and Quick Look previews.

- Japanese support: `index.html`
- Japanese privacy policy: `privacy.html`
- English support: `en/index.html`
- English privacy policy: `en/privacy.html`

This repository contains support-site files only. It does not contain the application source code or user photo files.
