VIEWEMON

Support

VIEWEMON helps you find photos across disks and folders you select on your Mac. It does not move, edit, or delete original files. AI-based categories and visual-similarity search run locally on your Mac.

Get started

  1. In Build33/34, choose a photo folder with “Add search location…”. In the planned Build35 resubmission, the same standard picker accepts your home folder, storage folders, an external data drive, or a folder such as DCIM within it, with multiple selection. Choosing the entire volume is not required. The startup-disk root, all of Users, and system locations cannot be added.
  2. The app does not request administrator privileges or Full Disk Access. It reads only locations authorized by macOS. Selecting home does not guarantee access to every protected child. Select additional locations yourself only when needed. Background processing never opens permission panels. Cancelling preserves cached browsing and search. Cloud-only iCloud items are not automatically downloaded. If media identity cannot be safely established, automatic reuse pauses and you can explicitly select the location again.
  3. Wait for the first index to finish; this may take time for large libraries.
  4. Find photos with search, categories, albums, or “Find similar photos.”

Troubleshooting

  • For missing photos, clear search and filters, check Hidden in VIEWEMON and Search Exclusions for folders and file formats, reconnect the original disk, and choose Sync now.
  • While a folder or file format is excluded from search, its photos do not appear in results. Removing the exclusion makes them eligible to appear again without deleting originals or saved index data. You do not need to re-add the search source or delete the index.
  • If access is denied, select the same photo folder again and grant access in the macOS picker. Protected locations may remain inaccessible.
  • RAW and document files without a usable embedded preview may not be displayed.

Keep separate backups of important photos. Before sending photos or index files to support, check that they do not contain personal information.
